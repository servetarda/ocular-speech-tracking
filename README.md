## Pipeline for Lexical, Syllablic, POS and Semantic Surprisal Calculations
This GitHub repository is the part of a project where we look at the relationship between Ocular Speech Tracking and Linguistic units. Under this repository, you will find multiple pipelines which you can use for predicton, entropy and surprisal metrics for Phonemic, Syllablic, Lexical and Syntactic units. I will store the pipeline under 4 separate file named "phonemic-predictions", "syllabic-predictions", "lexical-predictions" and "syntactic-predictions. Finally, I will put them in a single file together where you can directly use and be good to go :) You can find a detailed information regarding the models and techniques used.
